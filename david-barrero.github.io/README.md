# david-barrero.github.io

Personal portfolio site for David Barrero, business and data analyst, hosted with GitHub Pages at https://david-barrero.github.io.

The landing page is a penalty kick: shoot the ball at a corner of the goal to jump to Projects, About, Resume, Skills, or Contact. A plain menu at the top works too.

Built with plain HTML, CSS, and JavaScript. No build step.

- `index.html` – page content (add new project cards in the Projects section)
- `style.css` – styles
- `main.js` – the shot animation
- `assets/` – headshot, resume PDF, and project charts
